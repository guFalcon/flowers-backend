Everything in the repos — Java and JavaScript identifiers, comments, log messages, docs,
OpenSpec artifacts, commit messages — is English. No German.

**Why:** Project-wide rule stated by Gerald.

**How to apply:** Anything you add or rewrite is English. Existing German comments (e.g. in
`GameResource`) are translated when a change touches that code anyway. User-facing game text is
a separate question — ask before deciding its language.
